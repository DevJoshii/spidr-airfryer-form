# Spidr Air Fryer Interest Form

A lightweight React widget built for Spidr Design’s new Air Fryer landing page.  
This single-page form captures visitor interest with the following fields:

- **First Name**  
- **Last Name**  
- **Phone Number**  
- **Email Address**  
- **Guess the Air Fryer’s Cost** (numeric input)  
- **Very, Very Secret 16-Digit Spidr PIN** (formatted `####-####-####-####`)  

On submission, the form simply logs the collected data to the browser console (per the challenge brief).
